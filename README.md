# Silicon+Light NOTES — 記事のコード

技術ブログ **[Silicon+Light NOTES](https://mig.tetsufuku-blog.com/)** の記事で使っている
コードとノートブックを置いています。

記事ごとにフォルダを分けています。フォルダ名は記事のスラッグと同じです。

| フォルダ | 記事 |
|---|---|
| `noise-shaping-python/` | [Python で見るノイズシェーピング — 量子化ノイズを帯域外へ追い出す](https://mig.tetsufuku-blog.com/posts/noise-shaping-python/) |

## 使い方

ノートブックは **出力を消した状態** で置いています。
実行すると図やデータが生成されます。Google Colab で開くか、手元の Python で動かしてください。

プロットのラベルは既定で英語です。日本語ラベルの図を作るときは `PLOT_LANG=ja` を付けて実行します（ブログ用）。
